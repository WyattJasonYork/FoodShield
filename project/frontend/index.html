FoodShield

面向外卖订单通信场景的匿名订单认证与可信审计系统：日常通信隐藏真实身份，异常争议可审批溯源，消息记录通过国密算法与 Merkle Root 支撑完整性验证。

技术栈

Flask Socket.IO 国密 SM4 Merkle Tree Bootstrap 5 SQLite
🔒 匿名 PID

后端生成并绑定匿名身份，普通用户与骑手界面不暴露真实身份映射。

🔑 订单 Token

基于订单号、时间戳与身份凭证进行认证，拦截伪造与篡改。

🛡️ SM4 加密存储

聊天内容入库前加密保存，管理员审计侧默认只看哈希与元数据。

📊 Merkle 审计

以消息哈希构建 Root，支持快照、完整性验证与三端一致性比对。
